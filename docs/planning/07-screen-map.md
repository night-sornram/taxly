# Application Screen Map

| Screen | การใช้งาน |
|---|---|
| Welcome + onboarding | เลือกปี คัดกรอง และเตรียมรายการตั้งต้น |
| Dashboard | ภาพรวมจริง/คาดการณ์ ภาษีจากข้อมูลที่มี และรายการต้องตรวจ |
| Income | ตาราง กรองเดือน/สถานะ เพิ่ม แก้ ลบ และยืนยันครบปี |
| Deductions | สิทธิ์พื้นฐาน สิทธิ์ยังไม่รวม และเงินสมทบรายเดือน |
| Explanation | สูตรทุกขั้น ตาราง band ข้อจำกัด และ source documents |
| History | ผลที่เคยบันทึก พร้อมบอกว่าข้อมูลปัจจุบันเปลี่ยนหรือยัง |
| Privacy | สำรอง ตรวจไฟล์ก่อนกู้คืน และลบข้อมูลทั้งหมด |

Navigation หลัก 4 ส่วนบนหน้าจอเล็ก; desktop มีทางเข้า explanation/history โดยตรง Dialog ใช้ native HTML dialog เพื่อจัดการ focus และ Escape

ฟอนต์ Noto Sans Thai อยู่ใน bundle ไม่เรียก CDN สีสถานะมีข้อความกำกับและกราฟมี accessible labels
