# MVP Scope และ Non-Goals

## รองรับ

macOS Apple Silicon, บุคคลเดียวแยกหลายปีภาษี, ผู้โสดตลอดปี อายุต่ำกว่า 65 ปี มีเฉพาะเงินเดือน/โบนัสในประเทศ ใช้สิทธิ์ส่วนตัวและประกันสังคม ม.33 ปี 2568/2569

รองรับหลายนายจ้าง ยอดจริง/คาดการณ์รายเดือน เครดิตหัก ณ ที่จ่ายที่อาจยังไม่ทราบ ประวัติ และไฟล์สำรองเข้ารหัส

## ยังไม่รวม

คู่สมรส อายุ 65 ปีขึ้นไป สิทธิคนพิการ เงินก้อนออกจากงาน ผลประโยชน์พิเศษจากนายจ้าง เงินได้ต่างประเทศ รายได้มาตรา 40(2)–(8) และลดหย่อนอื่น เช่น ประกัน กองทุน ครอบครัว บ้าน หรือบริจาค

คำตอบนอกขอบเขตยังบันทึกเงินเดือนได้ แต่หน้าจอแจ้งว่าผลเป็นภาพจากข้อมูลพื้นฐานและงดสรุปยอดชำระ/คืน

ไม่มี Backend, registration, analytics, Cloud Sync, OCR, การขายผลิตภัณฑ์ การยื่นแบบ หรือการคำนวณ payroll withholding ให้นายจ้าง

Windows/Linux/mobile เป็นงานถัดไป ยังไม่ถือเป็นแพลตฟอร์มที่ตรวจรับแล้ว
