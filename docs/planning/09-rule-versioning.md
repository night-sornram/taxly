## Release gate ที่ยังเปิดอยู่

ยังต้องยืนยันการปัดเศษระหว่างขั้น ครึ่งสตางค์ จุดหักเครดิต และยอดคืนกับแนวปฏิบัติ/ระบบของกรมสรรพากร ห้ามอนุมานว่าปัดลงทุกช่อง การเปลี่ยน flag อย่างเดียวไม่ถือว่าผ่าน ต้องเพิ่มหลักฐานและ fixtures ที่ครอบคลุมก่อน

ปี 2569 ยังต้องเทียบคู่มือประจำปีเมื่อเผยแพร่ การยังไม่พบแบบ 90/91 ในหน้าปีนี้ไม่ได้หมายความว่ากฎหมายยังไม่มีผล

ประกันสังคมใช้ตามจริงที่เข้าเงื่อนไข ไม่เติมยอดสูงสุด: กรอบปกติ 2568=750 ต่อเดือน/9,000 เต็มปี; 2569=875/10,500 ต้องตรวจอัตราลดเฉพาะพื้นที่/เวลา การส่งเกินและเงินคืนด้วย

## การเปลี่ยนชุดกฎ

ก่อน release แรกสามารถแก้ชุดพัฒนาได้ หลัง release ให้ freeze payload/ID/hash ทุกครั้งที่เปลี่ยนสร้าง ID/version ใหม่ เก็บชุดที่ snapshots อ้างอิงไว้ แจกผ่าน app release และเพิ่ม catalog registry ไม่ดาวน์โหลด arbitrary rules

Catalog ตรวจ SHA-256 กับ manifest ที่ compile มากับแอป Restore ตรวจ rule references กับ catalog นี้ ไม่ใช้ hash ที่ผู้ส่งไฟล์อ้างเองเพื่อรับรองกฎใหม่

`bands.rate` เก็บอัตราตามกฎหมาย ส่วน `net_income_exemption` เก็บวงเงินยกเว้นและแหล่งกฎแยกกัน Core หักส่วนที่ได้รับยกเว้นก่อนคูณอัตรา และส่งทั้งอัตราตามกฎหมาย อัตราที่ใช้จริง และยอดยกเว้นในแต่ละช่วงให้ตรวจสอบ

เมื่อขยายเงินได้อื่นต้องเพิ่มวิธี 0.5% และข้อยกเว้นตาม [คู่มือกรมสรรพากร](https://www.rd.go.th/555.html) รวมหน้าที่ครึ่งปีสำหรับประเภทที่เกี่ยวข้องก่อนเปิดใช้
