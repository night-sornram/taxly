# Product Requirements Document — Taxly

เป้าหมาย: ผู้ใช้เห็นรายได้ ภาษีโดยประมาณ เครดิตที่หักแล้ว และข้อมูลที่ยังขาด โดยไม่ต้องรู้กฎหมายก่อนใช้แอป

กลุ่มเริ่มต้นคือผู้เสียภาษีครั้งแรกและพนักงานเงินเดือน ส่วนผู้มีหลายประเภทเงินได้เป็นระยะถัดไป ผลิตภัณฑ์ใช้ภาษาไทยและไม่ขอสมัครบัญชี

## พฤติกรรมที่ส่งมอบ

- Onboarding แบบคำถาม มีคำตอบไม่แน่ใจและเก็บขั้นที่ค้างไว้
- Dashboard แยกยอดจริง/คาดการณ์ ระบุขอบเขตและความครบถ้วนก่อนแสดงผล
- รายได้เงินเดือน/โบนัสจากหลายนายจ้าง แก้ ลบ และเปลี่ยนสถานะได้
- ตรวจสิทธิ์พื้นฐาน อธิบายวิธีคิดทุกขั้นและเปิดเอกสารต้นทางได้
- ประวัติผลสรุปมี input, rules hash, engine version และ data revision
- สำรอง/กู้คืนแบบเข้ารหัสโดยไม่ต้องมีอินเทอร์เน็ต

## เกณฑ์ผลิตภัณฑ์

ผู้ใช้ใหม่ 4 จาก 5 คนควรทำกรณีพื้นฐานได้ในประมาณ 5 นาทีและอธิบายได้ว่าทำไมภาษีศูนย์ยังอาจต้องยื่นแบบ เกณฑ์นี้ต้องทดสอบกับมนุษย์จริง ยังไม่ถือว่าผ่านจาก automated tests

ทุกผลเป็นประมาณการ ไม่ส่งแบบ ไม่ชำระภาษี และไม่รับรองยอดโดยกรมสรรพากร
